# Native Preview 0.6.5.1 — приёмка

Ветка: `codex/native-awg-installer-preview`. Исходный коммит клиента: `8e38a98`.
Это предварительный выпуск; стабильный 0.6.4 не заменён.

## Комплект

EXE Setup: 64 217 121 байт. Облегчённый ZIP: 68 343 273 байта.
Нативные компоненты встроены в оба пакета; .NET загружается отдельно при отсутствии.
Архив соответствующих исходников нативных компонентов предоставлен отдельным
файлом и не увеличивает размер обычного установщика.

Включённые в пакет C#-исходники агента и GUI побайтово сверены с отправленной
веткой. Личные профили, ключи, журналы, рабочие данные и конфигурация DE-2
в Git и артефакты клиента не включены.

## Проверки

- Build-All: сборка и самопроверки агента успешны.
- Windows 11: проверка ZIP, manifest, агента и GUI успешна. Проверка комплектного
  архива дополнена отказом при неверном SHA-256, отсутствии файла, некорректном
  digest и отмене подготовки; прежняя поставка без bundle сохраняет download-путь.
- EXE: полная штатная Verify-Installer с отдельным тестовым AppId успешна:
  установка/удаление и предусмотренные сценарии обновления, одинаковой/старой
  версии, прерванного копирования и восстановления. Это изолированные fixture-
  сценарии, не установка поверх работающего подключения основного ПК.
- Нативный комплект: отказываемся упаковывать непроверенные исходники или
  любой из трёх бинарных файлов с несовпадающей квитанцией.
- Свежая сборка агента как настоящая RoutePilotRescue в Windows 11:
  HTTPS/UDP через TUN, импорт из desktop IPC, приватные ACL, сохранение импорта
  при отмене/ошибке, восстановление дочернего транспорта/core/службы, ручной
  Stop после перезапуска, maintenance и отказ устаревших команд — успешны.
  Квитанция: `runtime/native-scm-b695ee74ba994116a5313bbf039de64a.json`;
  хеши owner/core/guard соответствуют распространяемому нативному комплекту.
- Прежняя служба ВМ восстановлена, кандидат удалён. Подключение основного ПК
  в ходе этих проверок не переключали.

Устаревший UI-тест ожидал пересоздания DataGrid при каждом изменении трафика.
Он заменён проверками уведомления привязанного счётчика: и для повторно
использованной строки, и для новой строки с тем же ID. Пересоздание таблицы
для прохождения теста не возвращали.

## Границы

Длительную проверку, reboot основного ПК, произвольные игры/QUIC/все домены этим
выпуском не подтверждаем. Результаты сервера DE-2 и лабораторного измерителя
не подменяют приёмку установленного приложения. Нативный режим включается явно;
при смене сервера с другим внешним IP сохранение каждой старой сессии не обещается.
