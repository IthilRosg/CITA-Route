# CITA Route 0.6.8 — Standalone Native Preview

Самостоятельный клиент WireGuard / AmneziaWG. WireSock не требуется.
Нет выбора, поиска и установки внешнего клиента, прежнего SOCKS-моста и скриптов подключения.
При обновлении удаляются только прежние служебные файлы внутри папки CITA.
Отдельно установленный WireSock, его профили и пользовательские .conf не удаляются.

## Запуск

1. Установи EXE. .NET скачивается отдельно, только если нужен.
2. Нажми «Подключить» и выбери IPv4 .conf с одним сервером. Затем CITA подготовит
   свою защищённую службу с подтверждением Windows.
3. После импорта подключение использует собственный движок. Следующие запуски используют сохранённый профиль.

AWG 3.1, AWG 2.0 и WireGuard поддерживаются, но доступность зависит от сервера и сети.
Автоподключение без подготовленного профиля не вызывает системные запросы автоматически.

## Границы preview

IPv6, команды запуска из конфигов и прежний редактор списков не поддерживаются.
Новые HTTPS-домены используют VPN, затем проверяется прямой путь. Смена внешнего IP
не гарантирует сохранение старых соединений. Долговременная устойчивость и все сайты
короткими тестами не подтверждены.
Новые preview устанавливаются вручную из GitHub Releases: прежний стабильный канал
автообновления отключён, чтобы он не вернул другую редакцию клиента.

Полные соответствующие исходники нативных компонентов, зависимости и offline-рецепт
воспроизведения трёх бинарных файлов публикуются отдельным source.zip рядом с установщиком.
Для обычной установки этот архив не нужен.
