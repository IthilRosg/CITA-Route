# CITA Route 0.6.5 — Native Preview

Тестовая ветка `codex/native-awg-installer-preview`. Это предварительная сборка,
стабильный выпуск 0.6.4 через WireSock остаётся доступным.

Установщик включает проверенный комплект нативного движка. .NET в установщик
не включён: при необходимости предлагается отдельная загрузка Microsoft Runtime.
Личные VPN-конфиги, ключи, журналы и настройки разработчика в комплект не входят.

## Запуск

1. Отключи текущий маршрут CITA и другие VPN, если они мешают соединению.
2. Установи эту версию обычным EXE-установщиком.
3. В расширенных настройках нажми «Подготовить встроенный модуль» и подтверди
   запрос Windows. Компоненты берутся из установщика после проверки SHA-256.
4. Импортируй собственный IPv4 `.conf` с одним сервером, выбери встроенный режим
   и подключись. Поддерживаются WireGuard, AWG 2.0 и AWG 3.1; фактическая
   доступность зависит от сервера и сети. IPv6 и команды запуска из профиля
   пока не поддерживаются.

Переключение на нативный режим выполняется явно, автоматически действующее
подключение WireSock не заменяется. Сохрани прежний рабочий профиль для возврата.
Для DE-2 предварительно удачнее показал себя AWG 3.1; MTU 1280 — кандидат для
отдельного теста пути, а не обязательное универсальное значение.

Сборка экспериментальная: короткие тесты Windows 11 и лабораторные проверки
не подтверждают доступность всех сайтов, игр, QUIC или долговременную устойчивость.
При смене сервера старые соединения могут закрываться; бесшовное сохранение
сессий при смене внешнего IP не гарантируется.

## Исходники

Исходники CITA находятся в указанной ветке репозитория IthilRosg/CITA-Route.
Полный соответствующий исходный код нативных компонентов, закреплённые зависимости
и рецепт воспроизводимой сборки предоставлены отдельным архивом source.zip
рядом с установщиком в предварительном выпуске. SHA-256 указан в SHA256SUMS.txt.
Комплект компонентов отказывается собираться, если исходники не прошли
проверку воспроизведения всех трёх бинарных файлов.
