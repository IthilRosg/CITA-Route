# Самостоятельный CITA Route 0.6.6 — приёмка

Исходный коммит: `02fc898`, ветка `codex/native-awg-installer-preview`.
Движок только нативный. WireSock не обнаруживается, не устанавливается и
не выбирается; старые транспортные RPC/CLI-команды запрещены. Legacy-контроллер
подключения до входа не запускается. В поставке нет WireSock-хелперов,
SmartRouting.ps1, Configure-Connection.ps1, smart-router.exe и vpn-bridge.exe.

Первый Connect готовит собственную службу и предлагает импорт `.conf`.
Подготовка проверяет хеш установленного агента: старая служба другой сборки
не считается готовым компонентом. Неактивная старая настройка boot-маршрута
может быть снята через прежнюю службу; активное подключение не прерывается
для этого автоматически.

## Проверки Windows 11 без WireSock

WireSock удалён штатным подписанным деинсталлятором в выделенной ВМ:
exit 0, CLI отсутствует, список его служб пуст. Основной ПК не затронут.

- Свежая служба 0.6.6: HTTPS/UDP через OS TUN, desktop IPC, импорт и его ACL,
  отмена/невалидный импорт без потери выбранного профиля, восстановление
  транспорта/core/службы, ручной Stop после перезапуска — успешны.
  Квитанция `native-scm-15349fe422d149d9af7b27a5e603c77c.json`, хеши совпали.
- Самопроверки распространяемых агента и GUI: успешны. Нативный выбор
  принудительный, WireSock-карточки и переключатель отсутствуют, видимые
  настройки проверены на отсутствие legacy-опций.
- Root discovery переведён со старого SmartRouting.ps1 на native package
  markers. Проверка запуска не требует возвращать удалённый legacy-файл.
- Включённый архив компонентов и каждый файл manifest проверены по SHA-256.
- Полная Verify-Installer с отдельным тестовым AppId: успешна; при проверке
  прерывания копирования используется настоящий native helper.
- Дополнительный переход: установлен настоящий гибридный test-setup 0.6.5,
  затем standalone test-setup 0.6.6. WireSockCli.ps1 и старый vpn-bridge.exe
  удалены, пользовательский data/personal.conf сохранён; uninstall exit 0.
- Настоящий EXE 0.6.6 обновил установленный клиент ВМ. Из его установленной
  папки выполнены Install-NativeAgent и Install-NativeComponents, затем импорт,
  подключение, HTTPS при активном туннеле и отключение — успешны.

Квитанции в runtime/vm-lab/w11: standalone-no-wiresock.json,
standalone-final-progress.json, standalone-upgrade-cleanup.json,
standalone-installed-acceptance.json. Первые неуспешные прогоны сохранены
для отладки; итоговая приёмка выполнена после исправления root discovery.
