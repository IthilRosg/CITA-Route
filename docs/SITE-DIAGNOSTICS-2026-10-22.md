# Проверка DeepL, Ryuugames и уведомлений о ресурсах

Дата: 2026-10-22. Основной установленный клиент — 0.6.0; тестовый пилот в ВМ —
0.6.1 из `7fdf4b7`. Изменения ниже подготовлены поверх ветки диагностики,
а не установлены поверх работающего пилота или клиента основного ПК.

## Фактические ответы сайтов

В ВМ выполнены собственные HEAD/GET без учётных данных через существующие
direct/DPI/VPN и обычный вход движка. Проверка сертификатов оставалась включена.
Режимы, профиль, текущие правила и установленные исполняемые файлы не заменялись.

| Адрес | Direct/DPI | VPN |
|---|---|---|
| `www.deepl.com/` | HTTP 451, `Unavailable in your region` | HTTP 301 на страницу сайта |
| `www.deepl.com/en/translator` | HTTP 451 | HTTP 200, HTML переводчика |
| `www.ryuugames.com/` | таймаут в пределах 6 с | HTTP 403, Cloudflare `Just a moment...` |
| `ryuugames.com/` | HTTP 403, Cloudflare challenge | HTTP 403, Cloudflare challenge |

Обычный вход движка в ВМ также вернул HTTP 200 для страницы переводчика.
Это проверка получения HTML, а не выполнения перевода, входа или прохождения
браузерной проверки. Для Ryuugames ответ Cloudflare нельзя объявлять ни полной
работоспособностью сайта, ни доказательством блокировки провайдером.

На основном ПК показаны `ERR_CONNECTION_CLOSED` сайта DeepL и `ERR_FAILED`
приложения. Найдены 32 записи hosts, перенаправлявшие DeepL и его службы на один
фиксированный адрес. Это отдельное отличие от ВМ с нормальным разрешением имён.
Подготовлена резервная копия и точечная правка; её применение не подтвердилось.
Затем hosts изменён параллельно пользователем/другим агентом, что подтверждено
пользователем. Новая редакция не перезаписывалась. Записей DeepL больше нет;
после изменения появились потоки сайта и службы входа через VPN с ответными
данными. Полная пользовательская операция DeepL ещё не подтверждена.

Установленный контроллер основного ПК выбрал VPN для `www.ryuugames.com`:
подтверждён поток Edge с приёмом около 3,9 МБ. Это не утверждение, что исчезли
все проблемы загрузки страницы или что все сторонние домены сервиса проверены.

## Изменения клиента

- Уведомления о ресурсах Windows выключены по умолчанию. Переключатель в
  настройках включает всплывающие сообщения и предупреждение компактного окна.
  Диагностический отчёт и работа службы наблюдения сохраняются.
- Две собственные HTTPS-пробы с HTTP 451 больше не сертифицируют путь как
  доступный. Контроллер может выбрать другой путь после двух успешных проб.
  Generic HTTP 403 не запускает смену ради обхода авторизации или Cloudflare.
  Ошибка сертификата по-прежнему запрещает заменять путь как способ скрыть её.
- Короткий FakeIP-поток мог исчезнуть до опроса API. Его входная запись содержит
  IP, а имя возникает в записи outbound. Парсер теперь связывает это имя с
  процессом того же потока и может инициировать проверку при ошибке соединения.
  IP-строки DNS не стирают уже установленное имя; чужой поток и сам агент не
  становятся основанием для такого решения.
- Версия стратегии кэша увеличена до `tls-record-ipv4-v3`: результаты прежней
  TLS-only проверки не переносятся как доказательство новой HTTP-семантики.
- Добавлена проверка одного домена `--check-site`: собственные DNS/HEAD через
  уже работающую сессию, без применения правил. Отчёт сохраняет HTTP-коды,
  выбранный путь и время проб; смена сессии/поколения делает результат непригодным.

## Проверки и ограничения

Сборка GUI и полный набор его существующих самопроверок прошли. Сборка агента
и его самопроверки прошли, включая новые сценарии HTTP 451, нейтрального 403,
ошибки TLS, смешанных ответов, короткого FakeIP-потока и миграции кэша. В сборке
агента остаётся прежнее предупреждение CA2022 в тесте UDP; новых ошибок нет.

Кандидат агента отдельно проверен в ВМ в 16:26:39–16:26:46 МСК, без установки
поверх пилота. После двух HTTP 451 на каждом из direct/DPI реальный селектор
выбрал VPN для DeepL: две успешные VPN-пробы, время кандидата 662 мс. Для
`www.ryuugames.com` выбран VPN после отказов direct/DPI примерно за 6,16 с;
VPN-кандидат ответил за 710 мс. Ответ HTTP 403 подтверждает достижимость
Cloudflare, но не прохождение проверки браузера. Ожидание приоритета direct
остаётся заметной задержкой; экспериментальный быстрый TCP не включался.

Длительный пилот продолжает использовать прежние исполняемые файлы. Небольшие
сетевые наблюдения добавлены 15:53:12–15:53:46, 16:17:30–16:17:32 и
16:26:39–16:26:46 МСК; при
оценке ресурсов эти интервалы нельзя выдавать за полностью простаивающий клиент.
Новые изменения не получили 12-часовую приёмку лишь за счёт продолжающегося
пилота другой сборки.

Зашифрованный HTTP-ответ реального браузера не читается контроллером. Исправление
451 применяется при запущенной собственной проверке пути; оно не добавляет
универсальное обнаружение любого короткого HTTP-отказа. Парсер коротких потоков
обрабатывает явные ошибки движка, а не все отказы TLS/HTTP после установления
TCP. События реальных потоков и более полная диагностика сервиса остаются
следующими задачами. Успех контрольного HTTPS не гарантирует работу всех сайтов.
