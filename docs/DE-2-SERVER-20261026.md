# DE-2 — развёртывание 26 октября 2026

Панель: https://awg-de2.citaeris.xyz

Сервер: 143.20.37.241, Ubuntu 24.04.5 LTS, 2 vCPU, 1919 MiB RAM.
Hostname: DE-2. SSH root:22, вход по существующему ключу; парольный SSH-вход отключён в исходной конфигурации провайдера.

## Установлено

- AWG-CITA 0.2.0, исходники https://github.com/IthilRosg/AWG-CITA, commit `564b0281ed37f774d2d35bdca735f37eeab51649`.
- Официальные amneziawg-go `v3.1.20260828` и amneziawg-tools `v3.1.20260812`, собраны на сервере.
- Python, segno, bcrypt, Caddy, UFW, инструменты сборки и сетевого управления.
- Root-owned код панели: `/opt/awg-cita/current/site`; рабочие службы под отдельным пользователем `awg-manager`.
- Вход через HTTPS-форму, короткоживущие защищённые cookies, CSRF, ограничение частоты запросов; внутренние API доступны только через Unix-сокеты.
- В статистику не передаются private key сервера, header-protection key и preshared keys. Фиксированный root helper проверен на синтетическом формате закреплённой версии AWG.

## Доступ

Логин панели: `awg-admin`.
Пароль хранится на сервере в `/root/DE-2-panel-access.txt` (0600).
Локальная закрытая копия: `runtime/de2-private/DE-2-panel-access.txt`; ACL разрешает доступ текущему пользователю и SYSTEM. Каталог runtime исключён из Git.
Ключи, конфиги и пароль в этот отчёт не включены. Присланный токен неизвестной панели не использовался.

## Службы и резервирование

`awg-canary0`, `awg-cita-awg2`, `awg-cita-wg`, `awg-cita-app`, `awg-cita-relay`, `caddy`: active и enabled.

Ежедневный `cita-de2-backup.timer`: закрытые архивы в `/var/backups/cita-de2`, 14 последних копий. Первый запуск успешен. Архивы содержат секреты, доступны только root. Это локальное резервирование, не защита от потери всего VPS.

Firewall разрешает SSH 22/TCP, HTTP 80/TCP, HTTPS 443/TCP и три VPN UDP-порта. Остальные входящие соединения закрыты стандартной политикой UFW. SSH после включения UFW повторно проверен.
