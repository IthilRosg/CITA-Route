# Обнаружение WireSock и совместимость

После уточнения пользователя: исходная проблема — поиск exe, не конфигов.
Get-WireSockInstallation сначала проверяет сохранённый путь и стандартные
Program Files (x64/x86), затем при необходимости реестр установки HKLM/HKCU,
службы WireSock, App Paths и пути запущенных процессов. Без сканирования дисков.
Из DisplayIcon/ImagePath извлекается только путь к exe, аргументы не исполняются.

Выбранный GUI WireSockConnect.exe или путь службы служит подсказкой корня:
проверяются соседние command-line, bin, cli и корень установки. Номер версии не
участвует в отбрасывании exe. Метаданные версии показываются пользователю.
Совместимый wiresock-connect-cli.exe выбирается перед LegacyClient даже при
сосуществовании редакций. Устаревший сохранённый путь не останавливает поиск.

wiresock-client.exe относится к другому CLI (run/install/config), его нельзя
вызывать командами управления профилями нового CLI. Он теперь обнаруживается
и показывается как LegacyClient, а не «не найден». Поддержка подключения этой
редакции требует отдельного backend и ещё не реализована. Аналогично GUI без
совместимого CLI показывается как ApplicationOnly. Последняя версия WireSock
для обнаружения не требуется; это не обещание совместимости любой версии.
Документация разных интерфейсов: https://wiresock.net/documentation/wiresock-secure-connect/command-line-interface

Перед чтением list действуют существующие требования Program Files, отсутствие
reparse points и действительная Authenticode подпись. Новые источники поиска не
дают права запускать произвольный найденный exe. Чтение списка ограничено 4 с
и 64 КиБ; ошибка доступа к службе не выдаётся за отсутствие программы.
Статистический IPC остаётся с отдельным проверенным контрактом 3.4–3.6;
расширение поиска не ослабляет его проверки версии и владельца pipe.

Verify-WireSockDiscovery.ps1 прошёл в PowerShell 7 и Windows PowerShell 5.1:
GUI/service/root layout, старая редакция, сосуществование, stale path, чужой exe,
quoted registry path. Это тесты обнаружения, исполняемые файлы фикстуры не
запускаются и не моделируют реальные старые версии. Полноценное подключение
старой версии на ВМ пока не подтверждено.

Настоящая проверка этого ПК вне sandbox: 3.6.1.1 обнаружен, три исходных профиля,
две папки профилей, без сообщения об ошибке, 757 мс. В sandbox pipe службы
недоступен; это ограничение среды, а не результат пользовательского клиента.
Новые исходники ещё не установлены поверх рабочего клиента и не опубликованы.
