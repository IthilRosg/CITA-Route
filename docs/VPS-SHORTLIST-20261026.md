# VPS для CITA-AWG из ЦФО — проверка 26 октября 2026

Это предварительный список для короткого теста, не результаты измерений
сети пользователя. Сервера не покупались, счета и обращения не отправлялись.
Сведения об оплате и размещении проверены по сайтам поставщиков.

## Предпочтительные варианты

1. **is*hosting: Хельсинки или Таллин.** Подходящий кандидат для проверки через
   криптовалюту: [официальные способы оплаты](https://help.ishosting.com/en/payment-methods-and-period-balance-replenishment-terms-of-crediting-payments)
   перечисляют Bitcoin и другие криптовалюты; российские карты этим списком не
   подтверждены. [Сервис прямо предлагает VPS для личного VPN](https://ishosting.com/en/vpn/vps-for-vpn).
   Нужен обычный root VPS для собственной CITA-AWG, не чужой управляемый профиль.
   [Looking Glass](https://ishosting.com/en/looking-glass) включает Хельсинки
   atNorth FIN01 и Таллин WaveCOM. Итоговая цена зависит от региона и конфигурации.

2. **Timeweb Cloud: Германия или Нидерланды.** Вариант с подтверждённой
   [оплатой картой РФ/СБП](https://timeweb.cloud/docs/service-payments/payment-methods).
   Есть [инструкция WireGuard через их маркетплейс](https://timeweb.cloud/tutorials/network-security/wireguard),
   но поддержку настройки WireGuard провайдер не обещает. Для CITA-AWG берём
   чистую Linux-машину и свою панель. [Финляндия у них только для выделенных
   серверов](https://timeweb.cloud/docs/nashi-data-centry), не VPS. Цену сравнивать
   с публичным IPv4 и выбранным зарубежным регионом, без годовой скидки.

3. **Veesp: Швеция или Латвия.** [VM 1 — $5/месяц](https://veesp.com/products/vps/):
   1 vCPU, 1 ГБ RAM, 20 ГБ NVMe; заявлен порт 1 Гбит/с. [Принимают криптовалюты](https://kb.veesp.com/billing/invoice-payment/),
   приём именно российских карт официальной страницей не подтверждён.
   На странице VPS есть возможность запросить трёхдневный trial через тикет,
   IP/файлы для теста: se-lg.veesp.com и lv-lg.veesp.com.
   [Fair use](https://veesp.com/sla/) запрещает постоянную высокую нагрузку без
   согласования; streaming/множество VPN-сессий с высокой нагрузкой согласовать.
   Условия trial и конкретную площадку подтвердить в момент заказа.

**Fornex пока исключён:** их [официальный FAQ](https://fornex.com/help/faq/)
прямо включает VPN services в запрещённые категории. Советы агрегаторов
не перекрывают это условие. **VDSina.com** рассматривалась, но конкретный способ
оплаты в этой проверке не подтверждён официальной публичной страницей; поэтому
не включена в основной список. Не путать условия сайтов .com и .ru.

## Как выбирать площадку

Хельсинки/Таллин — моя стартовая гипотеза для проверки из ЦФО по географии,
а не измеренный победитель. Следующие кандидаты — Стокгольм, затем Германия/
Нидерланды. Фактический маршрут оператора может поменять этот порядок.
Проверять из домашней сети без VPN к тестовому адресу выбранной площадки:
потери, разброс задержки, полезную скорость вечером; после аренды — именно
зашифрованный UDP/AWG, загрузки и параллельные приложения. Один ping не
подтверждает работоспособность туннеля и доступность сайтов с серверного IP.

Для начала разумен обычный x86-64 KVM, выделенный публичный IPv4, root,
1–2 vCPU и 1–2 ГБ RAM (для Docker/панели удобнее 2 ГБ), месячная оплата.
Это инженерная стартовая конфигурация, не обещание конкретной скорости.
Сравнивать включённый трафик, fair use, UDP и скорость одного ядра;
рекламный порт 1/10 Гбит/с не равен гарантированной скорости AWG.

Если нужен резерв, выбирать другую реальную площадку/оператора/ASN,
а не второй адрес той же машины. Наличие доступного HTTPS ещё не доказывает,
что UDP туда пропускает российский провайдер. До успешного короткого теста
не оплачивать год и не переносить действующий сервер.
