# Установка поверх существующей CITA Route

Правила установщика:

| Состояние | Действие |
|---|---|
| Программа отсутствует | Обычная установка в выбранную папку |
| Установщик новее программы | Обновление в прежней папке, сохранение личных данных |
| Версии равны | Предупреждение и предложение восстановить файлы; по умолчанию отказ |
| Установщик старее программы | Предупреждение и отмена понижения для защиты настроек |
| Версия установленных файлов повреждена | Отказ от непроверяемой замены |
| Обычный маршрут активен или клиент открыт | Замена заблокирована существующей защитой установки |

Сравнение числовое, до четырёх компонентов: `0.6.4` и `0.6.4.0` равны.
Проверка выполняется в защите установки под блокировками до остановки нативной
службы и замены файлов. Подтверждение привязано к прочитанной версии; смена версии
между предупреждением и продолжением проверяется заново. Тихая установка равной
версии без подтверждения завершается отказом. Тестовый параметр подтверждения
существует только в отдельной сборке установщика для ВМ.

`Verify-Installer.ps1` запускает настоящий отдельный Inno-установщик в Windows 11.
Более старая и новая установленная версия моделируются через `product.json`,
как при обновлении клиента независимо от регистрации старого установщика.
Это не сертифицирует совместимость настроек всех исторических выпусков.

Матрица дополнена проверками отказа от равной версии, подтверждённого восстановления,
запрета понижения и обновления старой установки. Сохраняются проверки ярлыков,
регистрации в Windows, автозапуска, Unicode-пути с пробелами, активного подключения,
прерывания копирования, независимого отката, удаления после обновления и установки
после удаления с сохранёнными правилами, настройками и приватными данными.

Физическая смена Wi-Fi/Ethernet, IPv6-транспорт и автоматические DPI/UDP-решения
остаются отдельными ограничениями нативного кандидата. Проверки установщика их
не закрывают. Длительные прогоны по текущему ограничению пользователя не требуются.
