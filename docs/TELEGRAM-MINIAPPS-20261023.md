# Telegram Mini Apps и папки WireSock — 23 октября 2026

## Причина сброса соединения

На основном ПК msedgewebview2.exe обращался к webappinternal.telegram.org:443.
Router log показывал outbound/direct и повторные таймауты. Статический Telegram
набор содержал IP CIDR, а поток с доменным SOCKS/FakeIP ещё не был сопоставлен с
IP. Telegram pinned-исключение запрещало авторутингу повторно изучать этот домен:
между двумя слоями правил получался пробел.

RuleFeeds теперь пишет также domain_suffix telegram.org, telegram.me, t.me,
tdesktop.com. Ensure-TelegramDomainRules идемпотентно дополняет старые файлы при
Prepare без потери IP правил. WebView2 учитывается в транспортном обнаружении
UDP/QUIC, но не получает идентичность браузера расширения.

Verify-RuleFeeds прошёл миграцию, идемпотентность и сохранение IP. В ВМ лог
подтвердил direct до изменения и vpn после; HTTPS корня вернул 404 с успешным TLS.
404 здесь подтверждает транспорт, не работоспособность приложения.

На основном ПК добавлены только domain rules в существующий Telegram JSON,
без перезапуска сети/маршрута и редактирования hosts. Резервная копия и хеши:
runtime/hotfix/telegram-host-hotfix.json. Сессия сохранилась. Пользователь повторно
открыл Stickers и BotFather и подтвердил загрузку обоих.

Это точечная установка доменного исправления в старую версию. Полный кандидат
не установлен; старый RuleFeeds до обновления может перезаписать файл при
обновлении списка. Постоянная миграция включена в исходники следующей версии.

## Обнаружение папок

Известные расположения WireSock Secure Connect:
- %ProgramData%\WireSock Foundation\WireSock Secure Connect\Profiles
- %LocalAppData%\WireSock Foundation\WireSock Secure Connect\Profiles

Configure-Connection Discover теперь возвращает только существующие каталоги.
В расширенных настройках кнопка «Папки профилей…» показывает найденные папки
и открывает выбранную в Проводнике. Диск целиком не сканируется; конфиги не
читаются и не копируются ради поиска. Профили для подключения по-прежнему
перечисляет CLI WireSock; произвольный скачанный .conf импортируется отдельно.
GUI собран без ошибок. Установленный клиент ещё не получил новую кнопку.
