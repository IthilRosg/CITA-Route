# CITA Route — Standalone Native Preview

Самостоятельный Windows-клиент WireGuard / AmneziaWG. Ветка `codex/native-awg-installer-preview`, версия 0.6.6.
WireSock не нужен: нет его поиска, установки и переключателя. Движок и маршрутизатор включены в установщик.

Семейство CITA: [AWG CITA](https://github.com/IthilRosg/AWG-CITA) управляет серверными интерфейсами и конфигами; CITA Route строит клиентские маршруты.

## Начало работы

Установи EXE, нажми «Подключить», подтверди подготовку собственной службы и выбери свой IPv4 .conf с одним сервером.
.NET скачивается отдельно, только если отсутствует. Последний импортированный профиль сохраняется.

[Установка и границы preview](docs/NATIVE-PREVIEW.md). Это предварительная версия; стабильный 0.6.4 остаётся отдельным прежним выпуском.
Новые preview пока устанавливаются вручную, чтобы старый канал обновления не вернул другую редакцию.

## Исходники и проверка

C#-часть и рецепты сборки находятся в этой ветке. Полный соответствующий исходный код нативных компонентов,
закреплённые зависимости и offline-рецепт воспроизводимой сборки публикуются отдельным source.zip рядом с EXE.
Компоненты упаковываются только после проверки совпадения всех трёх воспроизведённых бинарных файлов.
Сборка: Build-Portable.ps1 -NativePreview -NativeSourceReceipt <квитанция проверенных исходников>, затем Build-Installer.ps1.
Основной ПК при сетевых проверках не переключается; для них используется Windows 11 ВМ.
