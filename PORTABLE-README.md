# CITA Route 0.5.3 — запуск на другом компьютере

Windows 10/11 x64. В архив включена среда .NET: отдельно устанавливать её не требуется.
WireSock Secure Connect должен быть установлен отдельно. Поддерживаются WireGuard и
AmneziaWG с одним peer и IPv4 сервера; имя сервера с IPv4-записью также подходит.

Для обычной установки скачай **CITA-Route-0.5.3-win-x64-setup.exe** из GitHub Releases.
Запусти установщик и нажми «Установить»: появятся ярлыки **CITA Route** на рабочем
столе и в меню «Пуск». В конце можно сразу открыть клиент. Папку с техническими
файлами больше не требуется распаковывать и выбирать самостоятельно.
Установка находится в `%LOCALAPPDATA%\Programs\CITA Route\client`; настройки,
журналы и правила хранятся рядом с клиентом. Для установки ярлыков права
администратора не нужны; подключение по-прежнему запрашивает разрешение Windows.

Повторная установка сохраняет личные настройки и правила. Перед повторной
установкой или удалением выбери **Отключить и выйти**. Активная сессия, повреждённое
состояние или незавершённая операция блокируют замену файлов. Удаление доступно
через «Установленные приложения» Windows и сохраняет личные данные для повторной
установки. WireSock, его профили и общая защищённая служба восстановления не удаляются.
Старые распакованные копии автоматически не удаляются; перед подключением из новой
копии останови маршрут старой. Сохранённое имя профиля доступно и в новой установке,
но защищённая настройка нового пути выполняется заново при подключении.

ZIP остаётся переносным вариантом. Следующие шаги относятся к нему:

1. Полностью распакуй архив в свою папку, например `Документы\CITA Route`.
   Запусти `RoutePilot.exe`. После настройки сохраняй эту папку на месте.
2. Нажми **Подключить**. Приложение найдёт WireSock и его профили.
   Если нужен выбор — само предложит список. Если профилей нет, предложит **Импорт .conf**.
   Существующий профиль с таким же именем не перезаписывается. Прошлый доступный
   профиль используется повторно; другой вместо удалённого не выбирается молча.
3. Подтверди запрос Windows. Приложение подготовит службу и управляемую копию,
   подключит её и проверит VPN-выход. Исходный профиль остаётся прежним.
   Внизу окна виден текущий этап; во время подключения кнопка позволяет отмену.
4. В WireSock нужны выключенные `Virtual Adapter Mode` и
   `Override profile split-tunneling settings with global ones`.
   Приложение проверяет эти параметры и не изменяет их молча.
5. Нажми **Подключить**. Активный профиль WireSock и поддерживаемая служба VPNUS
   будут остановлены автоматически, исходные профили сохранятся. Неизвестный VPN
   или маршрут другой копии CITA Route приложение попросит остановить отдельно.
   При отмене или ошибке оно попытается вернуть прежний профиль и запустить
   остановленную службу VPNUS. Успешное соединение прежнего VPN этим не гарантируется.

Меню **⋮ → Расширенный вид** открывает все разделы, правила и глубокие настройки.
Переключение вида не переподключает сеть. Крестик по умолчанию скрывает окно в трей;
**Отключить и выйти** сначала останавливает маршрут. Мини-статистика относится
к сессии CITA. Задержка и оценка потерь VPN берутся из действующей службы WireSock;
дополнительный сервер не нужен. Задержка — оценка по последнему handshake,
потери — оценка ядра туннеля. Если данные недоступны, показывается «—».
Отдельные UDP-пробы Direct/VPN доступны в расширенных настройках при наличии
контрольного сервера. Проценты потерь из ошибок HTTPS не вычисляются.
Инструкция и сервер: [UDP quality](https://github.com/IthilRosg/CITA-Route/blob/main/docs/UDP-QUALITY.md).

В «Правилах» режим **Авто** подбирает прямой доступ, встроенную TLS-фрагментацию
и VPN. Приоритет — работающий прямой доступ. Сайты из списков ограничений по
умолчанию идут через VPN. Для проверки DPI на них есть отдельный переключатель.
Пользовательские правила выше автоматических; OpenAI и Telegram закреплены за VPN.

Обход DPI встроен в маршрутизатор. Он работает с IPv4 TCP/443, не гарантирует обход
любой блокировки и не распространяется на UDP/QUIC. Настройки маскировки AWG
берутся из твоего профиля; это отдельный от TLS-фрагментации механизм.

Проверка VPN сравнивает HTTPS-выход с внешним IPv4 из статуса WireSock. Адрес
UDP-сервера и адрес выхода могут различаться. Если WireSock не сообщает внешний IP,
укажи известный внешний IPv4 своего VPN в дополнительных настройках подключения.
Смена профиля и повторная установка доступны после отключения RoutePilot.
После изменения DNS-адреса VPN-сервера повторно примени подключение: маршрут и
защищённая служба используют согласованный IPv4 сервера.

Автономные тесты с временным отключением VPNUS предназначены для компьютеров,
где он установлен и настроен. Они не нужны для обычной работы на новом ПК.
Служба восстановления и монитор обычной сессии работают без VPNUS.

Архив не содержит чужих VPN-профилей, ключей, токенов контроллера, истории и журналов.
Не отправляй другу свою уже настроенную папку: используй чистый ZIP из `dist`.
Для удаления сначала отключи RoutePilot. Службу можно удалить из PowerShell
администратора: `Stop-Service RoutePilotRescue; sc.exe delete RoutePilotRescue`.

Компоненты и лицензии перечислены в `THIRD-PARTY.md` и `licenses`.
Исходники приложения находятся в `source`, исходники маршрутизатора — в `licenses`.

Обновления: меню **⋮ → Проверить обновления**, либо расширенные настройки. Проверка
также выполняется при запуске и раз в 6 часов. Загруженное обновление устанавливается
после проверки пакета: свой маршрут приложение отключит автоматически; соединения прервутся.
Чужой маршрут и автономная диагностика блокируют установку. После обновления нажми
**Подключить**. Следующее подключение при необходимости
обновит защищённую службу через обычный запрос Windows.
