# Components in the Windows distribution

- CITA Route sources (Apache-2.0) are supplied in `source`; PowerShell lifecycle scripts are at the package root.
- `vpn-bridge.exe` is the unmodified, hash-pinned sing-box 1.14.3 release, Copyright nekohasekai / SagerNet, GPL-3.0-or-later with the naming condition in its LICENSE.
- `smart-router.exe` is **CITA routing core 1.14.3-cita.3**, a separately branded modification of those pinned sources and sing-tun commit `bca4bf029237`. Its Windows DNS exception permits only Quad100 port 53 over active Tailscale adapter LUIDs, within the engine's existing dynamic filtering session. It does not disable the general DNS block. Its bounded `cita-fallback` DNS transport preserves valid negative responses and uses explicitly configured child transports. Its QUIC metadata cache retains an already sniffed IPv4/443 domain for at most 30 seconds and 1024 entries, scoped to process ID/path, inbound, source/destination tuple, QUIC version and Initial connection ID; it stores no packet body or routing decision. This derivative has no upstream affiliation. The original licenses, GPL text, original release source, modified core/TUN source archive and build version output are in `licenses`. The modified archive includes `CITA-MODIFICATIONS.txt` and pinned go.mod/go.sum; the repository contains `Build-RouterEngine.ps1` and `engine-patches`. Upstream: https://github.com/SagerNet/sing-box/tree/v1.14.3 .
- .NET 10 runtime and Windows Desktop runtime, Microsoft and contributors, redistributed with self-contained applications. License and third-party notices are in `licenses`. Source: https://github.com/dotnet/runtime and https://github.com/dotnet/wpf .
- Public routing lists: https://github.com/itdoginfo/allow-domains and https://core.telegram.org/resources/cidr.txt . These lists are not user VPN configurations.
- WireSock Secure Connect is a separately installed product; its binaries and driver are not redistributed in this ZIP.

The included router performs TLS record fragmentation. No ByeDPI or separate DPI driver is bundled.
